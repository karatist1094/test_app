Проект запускается командой "docker compose up -d",
Выключается "docker compose down"

Фронтенд запущен на localhost:5500, 
Бэкэнд запущен на localhost:8080, 
База Данных запущена на localhost:5432


Документация api: localhost:8080/docs

Смотреть проект на localhost:5500 (там фронтенд, видимая часть проекта)


Чтобы запустить проект, сначала git clone <url репозитория>, затем в Powershell (Win+R -> Powershell) прописать cd <путь к папке проекта, куда склонировался репозиторий> и запустить "docker compose up -d"
